La messagerie de la famille

Chiffrée de bout en bout. Effacée au bout de sept jours. Hébergée chez vous, pas chez quelqu'un d'autre.

Installer chez soi Voir le code

Rien ne s'accumule

Tous les messages disparaissent au bout de sept jours, sur le serveur comme sur chaque téléphone. Pas d'épinglage, pas de favoris, pas de réglage à trouver.

Personne ne lit par-dessus votre épaule

Pas même la machine qui transporte les messages, ni la personne qui l'héberge. Et il n'existe aucune porte dérobée parentale : un administrateur gère les membres, il ne lit pas leurs conversations.

Un seul groupe

Toute la famille, plus des conversations en tête-à-tête. Personne ne se demande jamais où écrire, et aucun groupe d'exclusion ne peut se former entre frères et sœurs.

Installer chez soi

Une machine, un nom de domaine, et une commande. Ni base de données à configurer, ni serveur de cache, ni reverse proxy : le certificat HTTPS est obtenu tout seul. 

# Récupérer le projet
git clone https://github.com/yoanbernabeu/locket.git
cd locket

# Démarrer — le certificat est obtenu automatiquement
SERVER_NAME=locket.mafamille.fr \
ADMIN_EMAIL=vous@example.com \
docker compose up -d

Ouvrez ensuite votre domaine : un assistant vous guide pour créer votre espace. Le guide d'installation détaille chaque étape, et le guide de dépannage couvre les cas qui coincent.

Ce que Locket ne fait pas

  • Pas d'appels audio ni vidéo. Vos proches ont déjà de quoi s'appeler. Les ajouter aurait rendu l'installation bien plus difficile, pour un bénéfice qui existe ailleurs.
  • Pas de confidentialité persistante par message. La compromission d'une clé expose les messages de la période concernée — bornée à sept jours. Nous préférons l'écrire que de le laisser deviner.
  • Les métadonnées ne sont pas chiffrées. Le serveur sait qui écrit à qui, et quand. Les masquer demanderait une architecture entièrement différente.
  • Perdre tous ses appareils, c'est perdre ses messages. Aucune clé n'est conservée sur le serveur. Le coût est faible : ils ne valaient que sept jours.
